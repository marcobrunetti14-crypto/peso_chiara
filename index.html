Il file dell'applicazione è pronto per il download: Icona HTML index HTML ⏱️ Guida Rapida e Urgente per l'Implementazione (Fogli Google + GitHub) Per collegare l'app al tuo foglio specifico e metterla online gratis su GitHub, segui questi passi immediati: PARTE 1: Configurare il Foglio Google (Google Sheets) Apri il tuo foglio Google. Assicurati che nella prima riga (Riga 1) ci siano esattamente queste intestazioni di colonna: Colonna A: Data Colonna B: Peso (kg) Colonna C: Note Nel menu in alto, clicca su Estensioni ➡️ Apps Script. Cancella tutto il codice presente nell'editor che si apre e incolla questo script: JavaScript function doPost(e) { try { var data = JSON.parse(e.postData.contents); // Apri il foglio usando l'ID fornito var ss = SpreadsheetApp.openById("1xM-9Ci2RtCWFG9xUOGJQtO-CUnE_bvbogMKmmMtJros"); var sheet = ss.getSheets()[0]; // Prende il primo foglio // Formatta la data per renderla leggibile var formattedDate = new Date(data.date); // Aggiunge la riga al foglio sheet.appendRow([ formattedDate, parseFloat(data.weight), data.notes ]); return ContentService.createTextOutput(JSON.stringify({"result": "success"})) .setMimeType(ContentService.MimeType.JSON); } catch(error) { return ContentService.createTextOutput(JSON.stringify({"result": "error", "error": error.toString()})) .setMimeType(ContentService.MimeType.JSON); } } Clicca in alto a destra su Distribuisci (Deploy) ➡️ Nuova distribuzione. Clicca sull'ingranaggio ("Seleziona il tipo") e scegli App Web. Configura i campi così (FONDAMENTALE): Esegui come: Tu (la tua email) Chi ha accesso: Chiunque (In questo modo l'app web potrà inviare i dati senza chiedere login a Francesca ogni volta). Clicca su Distribuisci. Se ti chiede di "Autorizzare l'accesso", dai tutte le autorizzazioni necessarie (cliccando su Avanzate -> Vai a Script). Copia l'URL dell'applicazione web che ti viene mostrato alla fine (sarà un link molto lungo che finisce con /exec). PARTE 2: Collegare l'URL all'HTML Apri il file index.html che hai scaricato con un editor di testo qualsiasi (anche il blocco note). Cerca la riga numero 150 circa, troverai questa stringa: JavaScript const SCRIPT_URL = "INSERISCI_QUI_URL_GOOGLE_APPS_SCRIPT"; Sostituisci INSERISCI_QUI_URL_GOOGLE_APPS_SCRIPT con l'URL lungo che hai appena copiato da Google Sheets. Salva il file. PARTE 3: Mettere l'App Online su GitHub (GitHub Pages) gratis Francesca potrà accedere all'app da un link sul suo telefono semplicemente facendo così: Vai su GitHub e accedi (o crea un account in 30 secondi). Clicca sul pulsante verde New per creare una nuova "Repository". Dai un nome alla repository, ad esempio: il-peso-di-baby. Imposta la visibilità su Public e clicca in basso su Create repository. Nella schermata successiva, clicca sul link che dice "uploading an existing file" (carica un file esistente). Trascina all'interno della pagina il file index.html modificato. Clicca sul pulsante verde in basso Commit changes. Ora vai nella scheda Settings (Impostazioni) della tua repository in alto a destra. Nel menu a sinistra, clicca sulla sezione Pages. Sotto la voce Build and deployment, dove dice Branch, cambia da None a main (o master) e clicca su Save. Attendi un minuto: GitHub ti mostrerà in cima alla pagina delle impostazioni il link pubblico (tipo https://tuonomeutente.github.io/il-peso-di-baby/).
